# Non-Dairy Base Reference

Stores approved formulations for non-dairy ice cream bases. All values are **per 100g of final output** (after straining and oil emulsification), so any batch size can be derived by multiplying.

Look up by **Base** name (case-insensitive). If the user's chosen ingredient matches an existing entry, offer to use it rather than re-deriving from scratch.

---

## Formulation Ratios (per 100g output)

How much raw ingredient, water, and oil go in to produce 100g of finished base.

> Raw ingredient weight is measured **after soaking** (soaked nuts weigh ~1.5× their dry weight). Oil column is 0 if no oil addition was needed.

| Base | Raw ingredient (g) | Water (g) | Oil (g) | Oil type |
|------|--------------------|-----------|---------|----------|
