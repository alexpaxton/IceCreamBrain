# What is this thing?

This is an AI powered tool for formulating, testing, and validating ice cream recipes. There's a series of skills that work together to aide in the process. More documentation to come later.

## Flavor explorer

Part of this project is a tool for creating flavor pairings called Flavor Explorer. You can view it on [github pages](https://alexpaxton.github.io/IceCreamBrain/). Any ingredient that I have looked up with the claude skills adds data to the flavor explorer app.
